
# YouTube Link Scraper & Niche Classifier

A simple tool to **find YouTube videos, collect their links, and organize them by niche**.

Instead of manually searching through hundreds of videos, this tool helps you collect and categorize YouTube links in one place.

## How It Works

The process is simple:

**Search → Scrape → Classify → Review → Export**

1. **Search** for videos using your desired topic or keywords.
2. **Scrape** the YouTube video links from the search results.
3. **Classify** each video into a niche and sub-niche.
4. **Review** the results and adjust the classification if needed.
5. **Export** the organized links as a CSV file.

## Example

You can search for a topic such as:

> skincare for beginners

The tool may organize the results like this:

```text
Beauty
└── Skincare

https://youtube.com/watch?v=ABC123
https://youtube.com/watch?v=DEF456
https://youtube.com/watch?v=GHI789
```

You can also define your own niche categories and sub-categories.

## What You Get

The final result is a clean list of YouTube links organized by:

* **Niche**
* **Sub-Niche**

For example:

```text
Beauty
├── Skincare
├── Makeup
└── Haircare

Finance
├── Saving
├── Investing
└── Side Hustle

Self Improvement
├── Confidence
├── Mindset
└── Productivity
```

The results can then be exported as a CSV file for further use.

## What This Tool Is For

This project is designed for anyone who needs to **collect and organize YouTube videos by topic**, especially when working with a large number of search results.

It focuses on the **links and their classification**, not on analyzing or rewriting the actual video content.
